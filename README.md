# SpendWise Dashboard - Week 6

A simple expense tracker for managing monthly budget.

## Features - Week 6 JavaScript Functionality
- Add new transactions (description, category, amount, type)
- Real-time calculation of Monthly Spend and Remaining Budget
- Transaction count display
- List of all transactions
- LocalStorage persistence (data stays after refresh)
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage API

## How to Use
1. Fill Add New Transaction form
2. Click Add Transaction
3. See totals update automatically
4. View transaction list

## Week 6 Requirements Met
- 4 files: index.html, style.css, script.js, README.md
- JavaScript with addEventListener, localStorage, calculateTotals(), renderTransactions()
